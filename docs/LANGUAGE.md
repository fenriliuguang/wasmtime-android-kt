# Documentation language

**English is the primary language** for this repository (README, scheme docs, RFCs, contributing).

Chinese is secondary. When a Chinese file exists, it uses the `.zh.md` suffix next to the English file, except:

| File | English (canonical) | Chinese |
|------|---------------------|---------|
| Root readme | [`README.md`](../README.md) | [`README.zh.md`](../README.zh.md) |
| Contributing | [`CONTRIBUTING.md`](../CONTRIBUTING.md) | [`CONTRIBUTING.zh.md`](../CONTRIBUTING.zh.md) |
| Third-party notices | [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) | [`THIRD_PARTY_NOTICES.zh.md`](../THIRD_PARTY_NOTICES.zh.md) |

If the two disagree, **English wins**.

Do not add a Chinese translation for every archive note. Archive material may stay in the language it was written in.

New RFCs and living scheme docs must ship in English. A `.zh.md` sibling is optional and should be a faithful summary, not a second source of truth.
